# 文件工作台对象分享 v1

## 最小范围

将已有 SharePanel 与 REST 分享能力接入文件行及对象详情。不新增分享模型、权限规则、存储接口、数据库迁移、SDK 方法或 UI 路由，不实现“分享给我”或恢复已有分享 token。

## 行为契约

- 活动文件行提供“分享”，打开内联对象分享面板；已删除文件不提供入口。对象详情提供“对象分享”页签，删除态禁用。
- 固定目标模式直接使用选中对象的 bucket 与完整 Key，Key 只读；不裁剪合法 Key 的前后空白或 `%` 等字符，不从文件名推导对象定位。现有 hash 解析亦保留对象 Key 空白，避免详情指向不同文件；不新增路由。独立“访问与发布”页面仍支持手动输入 Key。
- 打开固定目标面板时加载其分享列表；创建、刷新、撤销全部复用现有 API 和当前 client，不转发普通凭据给分享 URL。403 或 access 未启用错误正常展示，不当作空列表或自动放宽权限。
- 分享设置沿用名称、密码、预览/下载、有效期与次数限制；至少选择预览或下载之一，避免后端的“双方为空时默认预览”被误认为无权限分享。
- raw token/可复制 URL 只来自本次创建响应，仅存当前组件内存，不写 hash 或浏览器持久存储。列表不恢复 URL；撤销刚创建的分享后清除其复制链接。
- 面板关闭、目录/mine/recycle/client 改变、文件列表刷新或卸载后隐藏旧结果；迟到的 create/list/revoke 响应不能显示到新目标，也不能触发旧目标的后续刷新。已发送创建或撤销请求可能仍执行，不承诺取消或回滚。
- 新入口只是使用体验，不等同于授予 share 权限：创建和列表仍受读取、独立 share 授权及租户状态约束；下载仍由 capability、资源状态和现有权限执行。分享继续按现有 Key 契约访问，不新增精确版本分享承诺。

## 验收

前端测试覆盖固定/手动目标、真实请求参数、特殊 Key、自动列表、创建/撤销/URL 清除、无权限分享设置、关闭/对象/client/目录切换与卸载隔离，以及回收站与详情页签。SQLite/local HTTP 测试覆盖 read≠share、显式 Deny、tenant mismatch/停用、已删除对象及撤销后访问失效。

执行 `make web-check` → `make build` → `make web-smoke`、`make check` 与 `python3 cli.py accept`，更新嵌入产物。浏览器冒烟只验证嵌入加载；外部身份联测与真实外部存储不属于本轮验收。
