### REQ-5 — D1: receiver 5xx/timeout degrades the read path, readiness stays up

Cells **bound "default" × (PUT, DELETE)**, receiver modes `500` and `hang`, harness config of AC-1.3 (MaxLag 4s / MaxBackoff 4s / HTTPTimeout 1s / ClaimTTL 3s). The readiness pin is `rt.Ready(ctx) == nil` — the exact dependency `/readyz` consults (`readyzHandler` 503 iff `extra.Ready` err, `http.go:108-110`; F11).

- **AC-5.1 (500 receiver: degraded, not failed).** Rows stay pending through transient retries (`delivered_at_ns==0`, `failed_at_ns==0`, `attempts` grows ≥1 across lease-gated re-claims); once `rt.BacklogAge(ctx)` reports `age > 4s` (the harness `MaxLag`), `rt.Ready(ctx)` MUST return `nil` (degraded warn-only, `probeAndRecord` `runtime.go:251-291`); re-assert `Ready()==nil` at the terminal transition (cumulative window == `MaxBackoff` 4s, `relay.go:145-153` — deterministic: degraded window ≈[4,6]s exists because the window-terminal POST fires only at the next failed delivery ≈6s, F9; no wall-clock upper-bound asserts). *New — bounded ~8s test.*
- **AC-5.2 (hang receiver: timeout does not wedge the read path).** The receiver blocks on the events route until released: the in-flight POST aborts at the harness `HTTPTimeout` (1s — `deliverFact` ctx `relay.go:88-91` + client `Timeout` `http.go:87-95`); rows remain pending; `rt.Ready(ctx) == nil` during the hang; **the loop continues** — a second claim/POST is observed (lease-gated re-claim ≈3s, `postCount ≥ 2` while the receiver still hangs, `attempts ≥ 2`). The release channel is closed in `t.Cleanup` **before** receiver/server close (no goroutine leak under `-race`, pattern `dav_relay_test.go:29-33`); after release the retry receives `202-echo` and the row converges to `delivered_at_ns>0` (postCount final ∈ {2,3} — the abort/release race decides, so the pin is `≥2` + delivered, never an exact count). *New.*
- **AC-5.3 (read path survives to terminal).** In both modes `rt.Ready(ctx) == nil` at every observation point (degraded window, during hang, and at terminal: 500 → `failed_at_ns>0`; hang → delivered). The cumulative-window terminalization itself is the sibling T-3 direction's pin — asserted here only as convergence, not as the classification pin. *New (D1 at the module surface; `Ready()==nil ⇔ /readyz 200` is transitive via F11).*
