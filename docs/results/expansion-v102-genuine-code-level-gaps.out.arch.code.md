# 已收到角色提示词

我已经理解了我的角色：**资深软件工程师 / Code Implementer**，负责将技术设计转化为高质量的代码实现。

但我还需要一些关键输入才能开始工作：

---

## 我需要你提供以下信息

### 1️⃣ 实现任务
你要我实现什么功能或组件？例如：
- 新的 API 端点
- 新的 Storage backend
- 新的 Worker/Job
- AI Pipeline 组件
- 重构某个模块
- 修复特定问题

### 2️⃣ 设计文档
请提供以下文档之一或多个：
- **架构设计文档**（`.arch.md`）— 描述整体架构和组件设计
- **实现计划文档**（`.impl-plan.md`）— 描述具体的实现步骤
- **原始需求文档** — 功能描述或用户故事

### 3️⃣ 目标和范围
简要说明：
- 要实现的具体功能列表
- 哪些是 must-have（必须完成）
- 哪些是 nice-to-have（可选）
- 是否有时间或范围限制

---

一旦你提供了上述信息，我将：

1. 🧠 研读设计文档，理解架构和需求
2. 📋 制定实现方案，确保覆盖所有功能点
3. 🔨 逐步实现代码，遵循 AGENTS.md 中的工程约束（单文件 ≤500 行、单函数 ≤50 行、圈复杂度 ≤10 等）
4. ✅ 确保 `make check` 通过（`gofmt`、`go build`、`go vet`、`go test`）
5. 📝 提交完整的代码实现报告

**请告诉我你要实现什么！**
